# Python 01 - 42 School

Solutions for the Python 01 exercises from 42 School.

This repository contains exercises focused on Python fundamentals and object-oriented programming.

## Topics covered

- Type hints
- Classes and objects
- Instance attributes
- Methods
- `__init__`
- Encapsulation
- Getters and setters
- Inheritance
- Method overriding
- `super()`
- `@staticmethod`
- `@classmethod`
- Nested classes
- Basic statistics and state tracking
